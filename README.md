# Overview

This project is a simple mobile application developed with React Native. It displays a Hello World message and basic information about the application.

My goal is to strengthen my mobile application development skills by learning how to create, structure, run, and test a React Native application. This project also serves as a foundation for developing a more complete mobile task management application.

The software displays a simple interface containing a Hello World message, project information, and a short description of the application.

[Video demonstration of the software](http://youtube.link.goes.here/)

# Development Environment

The software was developed using the following tools:

- Visual Studio Code
- React Native
- Expo
- Android Emulator
- Node.js
- Git
- GitHub

The programming language used for this project is **JavaScript**. React Native is used to build the mobile application interface and components.
